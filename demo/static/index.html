📹 Connect to Google Meet

To analyze live meeting captions, install the Hush Chrome Extension:

  1. Open chrome://extensions in Chrome
  2. Enable Developer mode
  3. Click Load unpacked and select chrome-extension/ folder
  4. Join a Google Meet call and enable captions (CC button)
  5. Click the Hush extension icon and Start Capture

You can still use the text input below to test Hush manually.
